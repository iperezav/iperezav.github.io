Research

Three main pillars: reachability of systems, optimization of Chen–Fliess series, and differential monoids.

Reachability of nonlinear systems
Input–output reachability, mixed-monotonicity, and Chen–Fliess series.
A reachable set is the set of states of a system resulting from a set of inputs and initial conditions. Knowing these sets ahead of execution is crucial for planning and controlling system outputs. Popular offline methodologies for nonlinear systems include Hamilton–Jacobi approaches, mixed-monotonicity, and set-propagation.

My contributions include:
  • • A reachable set overestimation using interval arithmetic.
  • • Extending mixed-monotonicity to Chen–Fliess series, yielding an Input–Output Mixed-Monotonicity (IOMM) framework.
  • • Extending differential analysis tools to Chen–Fliess series to improve IOMM outcomes.

Optimization of Chen–Fliess series
Gradient descent, Newton–Raphson, and higher-order analysis.
Optimization is pervasive across scientific disciplines. In nonlinear optimization, line search and trust region methods stand out, tied to first- and second-order derivatives. The former uses gradients, while the latter relies on Hessians and benefits from accurate second-order approximations.

My contributions include:
  • • Closed forms of Fréchet and Gâteaux derivatives, gradients, and Hessians of Chen–Fliess series.
  • • First- and second-order Mean Value Theorems for Chen–Fliess series using the Chen–Fliess series of the sum of two inputs, enabling Taylor expansions.
  • • Implementations of gradient descent and Newton–Raphson algorithms to optimize Chen–Fliess series.

Differential monoids
Noncommutative algebra for differential analysis of Chen–Fliess series.
I introduced the theory of differential monoids to formalize differential analysis of Chen–Fliess series, building a bridge between noncommutative algebra and analysis. The alphabet is extended with differential letters representing differentiation, and a derivation operator on the free monoid is defined, satisfying the Leibniz rule.

Several properties of this derivation operator, including its interaction with the shuffle product, reveal the combinatorial nature of the differential monoid. A key result is that when Fréchet and Gâteaux derivatives exist, they are algebraically equivalent. The main theorem establishes a commutative diagram between the Gâteaux/Fréchet derivative and the language derivative on the differential monoid, showing that the derivative of a Chen–Fliess series equals the Chen–Fliess series of the derivative of its generating series.

Software

Open-source tools for simulating and optimizing Chen–Fliess series and control-affine systems.

ChenFliessSeries.jl
Julia library for Chen–Fliess series simulation.
First release: January 2026 · Version: 1.0.0 · MIT License
The ChenFliessSeries.jl package is a Julia library to simulate the output of nonlinear control-affine systems via Chen–Fliess series. It adapts the CFSpy package from Python to Julia, computing the list of coefficients and iterated integrals up to a truncation length.
Julia Chen–Fliess series Control-affine systems

Repositories: GitHub (Julia) · Documentation: Read the Docs
CFSpy
Python library for Chen–Fliess series and related computations.
First release: July 2024 · Version: 1.2.3 · MIT License
CFSpy (Chen–Fliess Series Python) is a set of functions to simulate the output of control systems via Chen–Fliess series. It computes coefficients and iterated integrals up to a truncation length, and provides routines for single iterated integrals and Lie derivatives, implemented in an object-oriented Python design.
Python Chen–Fliess series Lie derivatives

Repositories: PyPI · GitHub · Documentation: Read the Docs
CFS-toolbox
MATLAB scripts for Chen–Fliess series simulation.
First release: September 2023 · Version: 1.0 · MIT License
The CFS-toolbox is a MATLAB library of scripts to simulate the output of nonlinear control-affine systems via Chen–Fliess series. It is the foundation of CFSpy (Python) and ChenFliessSeries.jl (Julia), computing coefficients and iterated integrals up to a truncation length.
MATLAB Chen–Fliess series Foundational toolbox

Repositories: GitHub (MATLAB) · Documentation: Read the Docs
